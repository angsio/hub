## My Technical Domain

With one Raspberry Pi 4B and one domain, Docker Compose deploys React with nginx 
and backend with express on a shared container network, including a Cloudflare tunnel 
to keep my home router untapped. Accounts are shared across all of them by a single 
extra auth service container, reaching every app on my domain.

Running it myself gives me the holistic view and teaches me the infrastructure of 
container networking and cloudflare deployment.

## Building

    - tools are retrieved by embedding so the agent does not degrade as tools
      are added, and the threshold is not yet doing real work at three tools

I like setting the flow of user experience and reinforcing that in my infrastructure
and applications. When it comes to my scheduling agent, it assesses whether it needs
tools when interacting with users. When tools are needed, it sends a description
of its goal so my RAG architecture can match it to the most relevant tool. 
While the system doesn't help much for three tools, laying down the agentic 
pipeline for the ability to scale is what I find important. It enables
me to tune individual pieces and measure their improvement such as retrieval accuracy.
